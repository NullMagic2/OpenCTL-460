# OpenCTL 460 0.3.3

The Line smoothing page now leaves a blank line between each option/description pair. Row spacing increases from 52 to 68 logical pixels. Sliders and percentages retain their alignment with each option title using the native font and track metrics at the monitor DPI.

The handwriting controls and footer move down by 96 logical pixels, and the window is 96 logical pixels taller to prevent overlap. Labels, descriptions, slider values and pen-processing behavior are unchanged from 0.3.2.
