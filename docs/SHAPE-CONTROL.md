# Drawing shapes with OpenCTL 460

Set Handwriting assistance to Off - drawing settings, then open Drawing aids.
Use the start marker to locate the emitted start. Enable Pause near the start to
close a shape when desired. Hold there briefly with the pen down to close; moving
spirals and repeated loops do not snap just because they pass the start.

Precision Hold uses full-screen hover positioning and constant Movement reduction
during each stroke. Lift to choose the next starting position. Higher smoothing
amounts still add lag; endpoint settling catches up during a pause in contact.
Automatic tilt is removed.

Version 0.3.10 improves shallow curves and direction-independent motion protection.
See [release notes](RELEASE-0.3.10.md) for measured results and behavioral limits.
